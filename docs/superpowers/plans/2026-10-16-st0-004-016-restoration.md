> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Snapshot-before-mutation with restore-only-owned semantics, and reset/uninstall as full reconciliation (ST0-004/016).

**Architecture:** New `system_snapshot.json` beside `settings.json` (atomic writes, slot-once semantics); capture helpers called at the top of enabling setters/workers; disablers/reset/uninstall restore from snapshot with assumed-default fallback; per-profile prior values per UUID+key consulted by disable and transfer-clear.

**Tech Stack:** Python `main.py` backend, `unittest` isolated fixtures on Windows (no `main.py` import, no live setters), Git Bash on PATH.

**Spec:** `docs/superpowers/specs/2026-10-16-st0-004-016-restoration-design.md`

## Global Constraints

- Windows: isolated fixtures only; never import the real root plugin; never execute real setters/lifecycle/installer/dispatcher. Follow `tests/test_profile_ownership.py` + `tests/test_backend_reservation.py` AST-extract + fail-closed builtins pattern.
- Git Bash on PATH for syntax checks (`bash --version` works).
- No `connection.autoconnect-priority 100` write on any path; no ST0-005/006 owner-model change (transfer-clear value source only, per D9).
- IPC signatures unchanged; frontend untouched.
- No version bump, no Stable/beta, no Watchdog, no delivery-transaction work (001/002/003/018 excluded).

## Review Focus

- A disabler must never touch state this version did not enable — expect foreign custom values byte-identical after all-false run.
- Round-trips must restore recorded baselines, not assumed defaults — expect snapshot values asserted.
- Reset must converge live state to declared defaults — expect `iw` off, NM conf present, dispatcher installed, profiles cleared, timestamped save.
- Missing snapshot slots must fall back visibly — expect fallback logging, no crash.
- Priority `100` must never be written — expect repo-wide grep clean.
